Text to Write — Test Page

Use this page to verify the extension after loading it in Firefox.

How to load the extension

  1. Open Firefox and navigate to about:debugging
  2. Click This Firefox in the left sidebar
  3. Click Load Temporary Add-on…
  4. Navigate to this folder and select manifest.json
  5. The extension loads — click the toolbar icon to open the sidebar
  6. Click any field below, paste your test text into the sidebar, and press Type it
